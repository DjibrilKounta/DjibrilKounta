# Djibril Kounta

**Développeur backend C# / .NET**

Je développe des API REST avec ASP.NET Core et des applications qui s’appuient sur PostgreSQL et Entity Framework Core. Je m’intéresse particulièrement à la validation, à l’autorisation et aux tests d’intégration. J’intègre aussi des fonctionnalités d’IA générative côté serveur, avec des réponses structurées et de la recherche documentaire.
