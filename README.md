# Djibril Kounta

**Développeur full stack .NET & React · IA générative · Unity**

Je conçois des applications web de l’API à l’interface, avec C#, .NET et React. J’intègre des assistants IA capables de s’appuyer sur des documents et de produire des réponses structurées. Je développe aussi des prototypes Unity qui communiquent avec des API .NET.
